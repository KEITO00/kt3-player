# KT3 Player

[English](#english) | [日本語](#日本語)

## English

Player for `.kt3` / `.kt4` files (Windows). A browser version is available at
<https://kt3.keitodaze.net/>.

### Features

- Plays loops at the loop points stored in the file, without a gap
- Lyrics (two lines) and the music video of `.kt4` files
- Scratching by dragging the record. The video follows for `.kt4` files
- Cue, 8 hot cues, loops, beat loop, beat jump, pitch, brake, spin, filter, 3-band EQ with kill
- Beat FX: echo out, gate, reverb, reverb out, filter out, roll out
- Separate volume and kill for vocal and instrumental tracks
- Sparks, chorus flash, beat lamps, metronome
- File information with `Ctrl` + `I`
- Discord Rich Presence (can be turned off)

Press `?` in the app to see all keyboard shortcuts.

### Download

Download `KT3 Player_x.x.x_x64-setup.exe` from
[Releases](https://github.com/KEITO00/kt3-player/releases) and run it.

- Windows 10 / 11 (64-bit)
- `.kt3` / `.kt4` files open in KT3 Player after installation
- The app checks for new versions on startup

If Windows shows "Windows protected your PC", select "More info" and then "Run anyway".

## 日本語

`.kt3` / `.kt4` を再生する Windows 用のプレイヤーです。ブラウザ版は
<https://kt3.keitodaze.net/> で使えます。

### 機能

- ファイルに保存されたループ位置で、途切れずにループ再生
- 歌詞（2 行）の表示、`.kt4` のミュージックビデオの表示
- レコードをドラッグしてスクラッチ。`.kt4` は映像も一緒に動きます
- CUE、ホットキュー（8 個）、ループ、ビートループ、ビートジャンプ、ピッチ、BRAKE、SPIN、フィルター、KILL つきの 3 バンド EQ
- ビート FX：ECHO OUT、GATE、REVERB、REVERB OUT、FILTER OUT、ROLL OUT
- ボーカルとインストの音量・KILL を別々に操作
- 火花、サビのフラッシュ、ビートランプ、メトロノーム
- `Ctrl` + `I` でファイルの情報を表示
- Discord への再生中の表示（オフにできます）

キー操作の一覧は、アプリで `?` を押すと出ます。

### ダウンロード

[Releases](https://github.com/KEITO00/kt3-player/releases) から
`KT3 Player_x.x.x_x64-setup.exe` をダウンロードして実行してください。

- Windows 10 / 11（64bit）
- インストール後は、`.kt3` / `.kt4` をダブルクリックで開けます
- 起動時に新しいバージョンを確認します

「Windows によって PC が保護されました」と出た場合は、「詳細情報」→「実行」を選んでください。
